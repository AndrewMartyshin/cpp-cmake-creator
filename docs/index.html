    cppcmakecreator

    C++ CMake Project Generator

    Автор: Мартышин Андрей Михайлович Группа: M3103

    Описание

    Расширение для Visual Studio Code, которое автоматизирует создание базовой структуры C++ проекта с системой сборки CMake. Плагин избавляет разработчика от ручного создания файлов и написания шаблонного кода, позволяя сфокусироваться на логике программы.

    Возможности

    • Быстрое создание папки проекта с валидацией имени.
    • Интерактивный выбор стандарта C++ (от C++11 до C++23).
    • Автоматическая генерация main.cpp и настроенного CMakeLists.txt.
    • Опциональная автоматическая сборка проекта через встроенный терминал (cmake + make).
    • Наличие кнопки быстрого вызова в статус-баре VS Code.

    Установка

    1. Скачайте файл cpp-cmake-creator-0.0.1.vsix.
    2. Откройте VS Code, перейдите в раздел расширений (Ctrl+Shift+X).
    3. Нажмите на "..." в правом верхнем углу и выберите "Install from VSIX...".
    4. Выберите скачанный файл.

    Использование

    1. Нажмите Ctrl+Shift+P (или Cmd+Shift+P на macOS).
    2. Введите Create C++ CMake Project и нажмите Enter.
    3. Следуйте инструкциям на экране. Альтернативно: Нажмите на иконку ⚙️ "C++ CMake Tools" в правом нижнем углу (статус-бар).
